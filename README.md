# Portfolio Debrief（组合复盘）

每日收盘，把盈亏来源、净值回撤和风险提醒后的实际仓位变化放在同一张表里，让管理者看清账户发生了什么，自己又做了什么。

首版面向主动管理基金经理：读取机构 OMS（订单管理系统）导出的持仓、成交和资产三份文件，在本机为每个产品生成一份 Excel 复盘表。个人投资者是后续目标用户。

## 复盘表里有什么

每个产品一份 XLSX，含三张表：

| 表 | 内容 |
|---|---|
| 持仓表 | 近 5 日净值、涨跌和股票仓位；一行「今日结论」写回撤所在警示线、浮亏面和今日操作，回撤提醒期间写提醒以来是否减仓；「重点持仓」写入选原因、提醒日数和提醒以来的操作；「今日成交」按日线涨跌幅粗略标注追涨、杀跌；下方明细保留逐只风控状态。 |
| 说明 | 每条规则、算法、试用门槛和缺数时的写法。 |
| 行为评估 | 回看最近 20 个交易日的四项：回撤提醒后的仓位、浮亏警示后的处置、追涨杀跌、交易频率。分开写当时的操作和之后的结果，两样都成立才写「缺陷」；样本不足或数据待核实时不下结论。 |

每天放入当天的导出再生成一次。导出和历史存进本机的每日账本，提醒日数、提醒以来的操作和行为评估都从账本累积。

以下摘自一个合成产品（虚构数据）2030-04-05 的复盘表：

> **今日结论**：距高点（2030-03-05）回撤 28.72%，已超 20% 警示线，提醒第 21 日；浮亏面大：浮亏超 10% 的持仓 2 只，合计占资产 52.58%；今日无升级，1 只临近下一条警示线；今日净买入 12.04 个百分点，换手 12.04%，首次提醒以来累计净买入 10.82 个百分点，股票仓位由 85.00% 到 80.49%，回撤提醒后未减仓；注意风险

| 项目 | 结论 | 行为（当时的操作） | 结果（之后的净值和价格） |
|---|---|---|---|
| 回撤提醒后的仓位 | 缺陷 | 账本首日（03-08）已超 10% 警示线，此前的操作未知，之后 20 个估值日累计净买入 10.82 个百分点，股票仓位由 85.00% 到 80.49%：未减仓 | 之后升到 20% 警示线，回撤由 13.04% 最深到 29.84%；提醒仍在 |

## Windows 下载试用

需要 Windows 10/11 x64 和桌面版 Excel，不用另装 Python。

1. 下载 [Windows x64 便携包（B2 试用版）](https://github.com/CyberYY2030/portfolio-debrief/releases/download/B2/portfolio-debrief-B2-windows-x64.zip)，完整解压到本机短路径，例如 `C:\持仓复盘`。
2. 双击「生成持仓表.cmd」，选择三份导出所在的文件夹，再选一个只有获准人员能访问的输出文件夹。第一次可以选包里的「试用数据」（虚构产品）。
3. 完成后会打开结果文件夹，每个产品一份 XLSX。试用数据只有一天，第三张表只写一句“账本只有首日……”；连续放入多日导出后才有内容。

重跑与手改保留、取数失败时的提示、经理机验收步骤见 [Windows 使用说明](windows/README.md)，包内的「使用说明.txt」是同一份。

## 输入文件

同一估值日的三份 OMS 导出放在同一个文件夹，文件名照下表，第一行是列名，列名照写（括号的全角半角也要一致）。其他系统的导出需先整理成同样的文件名和列名。

| 文件 | 必需列 |
|---|---|
| `各产品持仓.xlsx` | 日期、产品、产品序号、单元、交易市场、证券代码、证券名称、币种、资产类别、证券类别、持仓数量、期初数量、当日买入数量、当日卖出数量、最新价、当日涨跌幅（%）、持仓市值(人民币)、持仓市值（本币）、当前成本（全价本币）、浮动盈亏、当日买金额、当日卖金额 |
| `成交查询.xlsx` | 发生日期、产品、产品序号、单元、交易市场、证券代码、证券名称、币种、证券类别、委托方向、成交数量、成交金额、成交金额(RMB)、总费用 |
| `资产查询.xlsx` | 日期、产品、产品序号、总资产、现金资产、股票资产、单位净值、单位分红金额、产品份额 |

缺必需列时生成停止并提示。某个产品的数据不合格时，只有这个产品改为校验说明，其他产品照常生成。

## 数据和联网

- 账户计算全部在本机完成，账户数据不上传。
- 生成时向腾讯行情接口请求两类公开日线：沪深300 指数；当天有成交且收盘已不持有的证券，这一类会发送证券代码。不发送产品、账户、持仓数量、成交数量或金额。
- 断网或取数失败时照常生成，页面和结束提示写明缺了什么。
- 输出目录含导出副本，请放在只有获准人员能访问的位置。

## 当前状态

B2 试用版（2026-11-15）。页面、规则和门槛已在合成数据上验证；连续多日的真实账本和经理 Windows Excel 实机尚未验收。警示线等门槛是试用值，写在「说明」里。复盘表用于看清风险和操作，不是交易指令，也不凭盈亏推定动机。

## 从源码构建便携包

代码在 `examples/oms_replay/`，只用 Python 标准库；便携包的入口 `windows/bootstrap.cmd` 运行其中的 `manager.py`。

准备 Python 3 和 Python 官方的 Windows x64 嵌入式运行包 `python-3.13.17-embed-amd64.zip`，放在仓库根目录，运行：

```sh
python windows/build_portable.py --runtime python-3.13.17-embed-amd64.zip --output portfolio-debrief-windows-x64.zip
```

构建脚本校验运行包的 SHA-256，并生成包内的虚构试用数据。
