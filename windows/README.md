# Portfolio Debrief（组合复盘） · Windows 使用说明

适用 Windows 10/11 x64 和桌面版 Excel。将便携 ZIP 完整解压到本机可写的短路径，例如 `C:\持仓复盘`。内含运行环境。账户计算在本机完成，生成前会自动获取公开的沪深300指数日线。

1. 将同一估值日的 `各产品持仓.xlsx`、`成交查询.xlsx`、`资产查询.xlsx` 放在同一个文件夹，保留这三个文件名。首次可用包里的「试用数据」，全部为虚构产品。
2. 双击 **生成持仓表.cmd**。首次选择导出文件夹和独立的本机输出文件夹，核对后点「确定」。输出含导出副本，请选只有获准人员能访问的目录。
3. 完成后打开本次估值日和版本的文件夹，每个产品一份 XLSX。第一张表「持仓表」从新版首页开始，第二张表「说明」解释规则、算法、试用门槛和缺数写法。
4. 次日放入新导出，再双击入口。同一天、相同内容重跑保留手改工作簿；导出更正、新版首页内容、指数或程序变化时另出一版，旧手改文件保留。新版本里的手工金额需经理核对并重新填写。
5. 移动输入目录或切换试用／正式数据时，双击 **更改目录.cmd**。试用与正式数据用不同输出文件夹。若终端禁止便携程序，请交由公司 IT 审核。

首页先读「今日结论」和「净值回撤」，再看「回撤期间操作」「重点持仓」「今日成交」。重点持仓写明入选原因、提醒日数和提醒以来的操作；其余提醒超过三只时逐只列名。下方明细的「风控提示」保留逐只完整状态。近 5 日表的「5 日累计」是区间收益，不是日期，也不累计仓位。

账本首日只有从当天开始的持仓历史，不能据此判断之前是否减仓。缺数原因及日期集中在「数据覆盖」。规则和定性词门槛都在「说明」，今日结论用于看清风险和操作，不是交易指令。

如果某产品新版页面计算失败，标题会注明 **新版首页生成失败，本页为旧版**；其他产品照常出新版。结束弹窗列出失败产品编号和原因，同目录 `V2_FAILURES.json` 留存原因。若历史导出校验失败、写盘失败或数据全部不合格，生成停止并报错，请按提示检查；不会把这些错误当作新版回退。部分产品未通过原数据校验时，该产品只有校验说明。

「持仓表」供经理编辑，「每日账本」保存历史和原始导出。不要修改账本中的留存文件。CSV 用于只读分析，编辑和公式留在 XLSX。目录设置保存在当前 Windows 用户的本地应用数据目录，不在便携包内。

双击生成时会自动取一次沪深300日线，存入输出目录的 `指数/沪深300.csv`。只连接腾讯行情接口，只发送指数代码、起止日期和条数，不发送产品、账户、持仓、成交或本机路径。整次取数最多等待 8 秒，不重试、不切换来源。

时间固定为东八区。当天 **15:30 之前不写当日指数**，防止使用盘中变化的数值；15:30 后重新生成可补齐。已有有效文件包含估值日这一行时不再取数，同日重跑沿用同一版，保留手改。若目录里已有经理手放的 `沪深300.xlsx`，程序不取数、不覆盖它。

断网、超时或接口格式改变，工作簿照常生成。结束弹窗和命令行会显示“沪深300 未取到：{原因}，本次页面不含当日指数；稍后重新生成会补上并另出一版”。没有指数文件时省略指数项；旧文件缺所需日期时，对应指数项写未知，在“数据覆盖”说明日期；无效文件整份不用。取数失败不改原文件。失败原因会用中文说明；有系统原文时，第二行“系统提示”可截图发给维护人排查。之后补到指数会另出一版，保留旧版手改。

也可手放指数文件：`沪深300.csv` 或 `沪深300.xlsx`，只放一种格式，含“日期”“收盘”两列。CSV 为 UTF-8，日期为 `YYYY-MM-DD`，收盘为正数，同日不能有冲突值。

第一次在经理机验收，用包里的试用数据生成并打开「合成二号」：

1. 确认第一张表有「今日结论」「净值回撤」和近 5 日表，第二张表名为「说明」，「5 日累计」显示文字；长名单、长句完整可读。
2. 在表尾找两行「场外」金额的黄色格，位于「冻结金额」列、小计上方。第一行填 `12500.50`，第二行填 `7500.25`。找「当日负债」旁的黄色格，改为 `400345.67`。
3. 检查同一表尾的「期末资产」为 `1,619,655.08`，当前单位净值显示 `1.6197`。首页净值仍取 OMS 收盘序列；手工表尾金额不会重写首页分析。
4. 保存、关闭、重跑入口，应打开同一版本并保留上述编辑。更正合成输入或补指数后重跑，应另出一版且旧版仍在。

验收按文字标签找格，不依赖固定行号。正式使用前由经理在 Windows Excel 核实公式重算、文字显示与手改保留，再通过「更改目录」切到正式目录。

盈亏说明覆盖收盘仍持有的证券。港股通的价格变化、买卖和费用按当天折算的人民币金额估算，汇率自身变化不列入贡献。
